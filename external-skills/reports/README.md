# External Skill Import Reports

Use this directory for audit notes before importing or merging external skills.

Import policy:

- Stage external skills before installing them.
- Map each candidate to an existing local skill, persona, workflow, or route.
- Prefer merge-reference or merge-workflow when an existing local skill already owns the capability.
- Use optional-install only for domain packs that should remain separate, such as GSAP.
- Never overwrite an existing local skill without a backup and comparison.
