# 에러 자동 해결 스킬

## 실행 흐름 (5단계 자가치유 루프)

### 0단계: 피드백 루프 확보 (필수)
수정 전에 사용자가 말한 실패를 재현하는 빠른 pass/fail 신호를 만든다. 이 단계가 없으면 추측 수정으로 흐른다.

우선순위:
- 실패 테스트
- CLI/HTTP 재현 명령
- fixture 입력 + stdout/stderr diff
- Playwright/Puppeteer 같은 headless browser 재현
- 캡처된 요청/로그/trace replay
- 최소 harness

확인 기준:
- 사용자가 말한 증상과 같은 실패인지 확인
- 여러 번 실행해도 재현되는지 확인
- 정확한 에러 메시지, 잘못된 출력, 느린 구간을 기록
- 재현 루프가 없으면 수정하지 말고 필요한 artifact나 접근 권한을 요청

### 1단계: 에러 분류
에러 메시지 + 스택 트레이스를 분석하여 유형 분류:
- 타입 에러 → 인터페이스/타입 수정
- import 에러 → 의존성 설치 또는 경로 수정
- 런타임 에러 → 로직 수정
- 빌드 에러 → 설정 파일 수정
- 테스트 실패 → 로직 또는 테스트 수정
- 알 수 없음 → 사용자에게 보고

### 2단계: 에러 KB 3중 검색
- 1차: ~/.Codex/memory/ontology/graph.jsonl에서 ErrorPattern 엔티티 정확 매칭
- 2차: ~/.Codex/memory/patterns.md에서 에러 메시지 토큰 유사도 검색
  - 방법: 에러 메시지를 토큰화 → 기존 패턴 토큰과 교집합/합집합 비교
  - 기준: 70%+ 유사도 → 매칭 인정, 최대 5개 결과
- 3차: ~/.Codex/memory/dead-letters.md에서 미해결 이력 확인 (재발 감지)
- 이력 있으면 → 즉시 적용 (빠른 경로)
- 없으면 → 새로 분석

### 3단계: 자동 수정
- 수정 전 상태를 git stash로 보존 (롤백 가능)
- healer 에이전트(@healer)로 수정 적용
- 재현 루프가 통과할 만큼만 수정
- 임시 로그는 고유 prefix를 붙이고 끝나면 제거

### 4단계: 재검증 + 회귀 테스트
- 동일 에러 재확인
- 기존 테스트 전체 실행 (새 에러 발생 안 하는지)
- stderr/warning까지 확인
- 통과 → 5단계
- 실패 → 다른 접근법 시도 (최대 3회)
- 3회 실패 → git stash pop 롤백 + dead-letters.md에 기록 + 텔레그램 알림

### 5단계: 학습 기록 (자동 캡처)
해결 성공 시 아래 형식으로 기록:
- **ErrorPattern 등록** (온톨로지): 에러 메시지 + 컨텍스트(파일, 라인, 명령) + 해결 diff 요약 + 명령 시퀀스
- **patterns.md 등록**: 에러 메시지 키워드 + 해결법 1줄 요약
- **instincts.md 기록**: 에러 해결 패턴 ★☆☆
- 자동 캡처 트리거: bash fail→success, 타입에러 fix→pass, 테스트 fail→success
- 다음에 같은 에러 → 2단계에서 즉시 해결

## Circuit Breaker
- 연속 3회 실패 → 중단 (Circuit Open)
- 동일 에러 재발 시 → 재시도 하지 않고 사용자에게 전달
- /autofix --reset → Circuit Close

## 비용 가드레일
- 자가치유 1회당 최대 토큰: 10K
- 세션당 자가치유 총 토큰: 50K
- 초과 시 → 중단 + "비용 한도 도달" 알림
