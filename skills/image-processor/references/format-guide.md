# 이미지 포맷 가이드

## 포맷별 용도 및 품질 설정

| 포맷 | 용도 | 품질 설정 |
|------|------|----------|
| JPEG | 사진, 썸네일 | `-quality 85-95` |
| PNG | 투명 배경, 로고 | `-quality 95` (무손실 지원) |
| WebP | 웹 최적화 | `-quality 80` (손실) / `-define webp:lossless=true` |
| AVIF | 차세대 웹 | `-quality 60-80` |

## 소셜 미디어 크기 기준

| 플랫폼 | 크기 | 비율 |
|--------|------|------|
| YouTube 썸네일 | 1280×720 | 16:9 |
| 인스타 피드 | 1080×1080 | 1:1 |
| 인스타 스토리/릴스 | 1080×1920 | 9:16 |
| X/트위터 헤더 | 1500×500 | 3:1 |
| 페이스북 커버 | 820×312 | ~2.6:1 |

---

## 포맷 선택 기준

- **투명도 필요**: PNG 또는 WebP (lossless)
- **파일 크기 최소화 (웹)**: WebP > AVIF > JPEG
- **호환성 우선**: JPEG
- **로고/아이콘**: PNG (무손실) 또는 SVG
- **배치 썸네일**: JPEG (빠른 처리) → 필요 시 WebP 변환

---

## 품질 선택 기준

| 용도 | 권장 품질 |
|------|----------|
| 소셜 업로드용 최종본 | JPEG 90-95 |
| 웹 임베드용 | WebP 80 |
| 중간 작업물 | JPEG 85 |
| 로스리스 보존 | PNG 또는 WebP lossless |
