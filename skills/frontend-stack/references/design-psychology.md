## 핵심 법칙

### Hick's Law (선택의 역설)
- **원칙**: 선택지가 많을수록 결정 시간이 로그적으로 증가
- **적용**:
  - CTA 버튼: 주 1개 + 보조 최대 1개
  - 네비게이션: 최상위 메뉴 5-7개 이하
  - 폼: 한 화면에 3-5개 필드
  - 가격표: 3개 플랜 (추천 1개 하이라이트)
- **측정**: 사용자가 3초 내 다음 행동을 결정할 수 있는가?

### Fitts' Law (동작 효율)
- **원칙**: 타겟이 클수록, 가까울수록 빠르게 도달
- **적용**:
  - 주 CTA: 최소 44x44px (모바일 48x48px)
  - 중요 버튼은 화면 중앙 또는 엄지 도달 범위
  - 관련 액션은 가까이 배치 (저장 + 취소)
  - 파괴적 액션(삭제)은 주 액션과 거리 두기
- **측정**: 모바일에서 한 손으로 주요 CTA 도달 가능한가?

### Von Restorff Effect (고립 효과)
- **원칙**: 나머지와 다른 항목이 기억에 남음
- **적용**:
  - 추천 플랜에 배지/색상 차별화
  - 핵심 기능에 아이콘/일러스트 강조
  - CTA 버튼 색상은 페이지 내 유일한 accent
  - 중요 알림: 주변과 대비되는 시각 처리
- **측정**: 페이지에서 단 하나만 기억한다면 그것이 핵심 CTA인가?

### Miller's Rule (작업 기억 한계)
- **원칙**: 단기 기억은 7+-2 청크 처리
- **적용**:
  - 네비게이션 항목: 5-9개
  - 기능 소개: 3-4개 그룹으로 청킹
  - 스텝 프로세스: 3-5단계
  - 카드 그리드: 한 줄 3-4개
- **측정**: 각 섹션의 정보 단위가 7개 이하인가?

### Gestalt 원칙 (지각 조직화)

| 원칙 | 설명 | UI 적용 |
|------|------|---------|
| **근접** | 가까운 요소는 그룹으로 인식 | 관련 필드 간격 줄이기, 섹션 간 간격 늘리기 |
| **유사** | 비슷한 요소는 같은 그룹으로 인식 | 같은 유형 카드에 동일 스타일 |
| **연속** | 시선은 부드러운 흐름을 따름 | F-패턴/Z-패턴 레이아웃 |
| **폐합** | 불완전한 형태를 완성하려는 경향 | 카드 일부 가림 → 스크롤 유도 |
| **공통 영역** | 같은 영역 내 요소는 그룹으로 인식 | 배경색/테두리로 섹션 구분 |

## 행동 유도 패턴

### 사회적 증거 (Social Proof)
- 고객 로고 / 사용자 수 / 후기
- 위치: Hero 직후 또는 CTA 직전
- 구체적 숫자 > 모호한 표현 ("10,000+ 팀" > "많은 기업")

### 손실 회피 (Loss Aversion)
- "무료 체험 종료까지 3일" > "지금 시작하세요"
- 제한 수량/시간 표시 (진짜인 경우만)

### 앵커링 (Anchoring)
- 가격표: 가장 비싼 플랜을 먼저 표시
- 할인: 원가 취소선 + 할인가 강조

### 점진적 공개 (Progressive Disclosure)
- 고급 옵션은 접힘 상태
- "더 보기" 패턴으로 인지 부하 분산
- 온보딩: 한 번에 하나씩

## 페이지 유형별 심리학 적용

### 랜딩페이지
```
Hero (Von Restorff + Fitts)
  → 하나의 명확한 CTA, 크고 대비되는 색상
Problem (Loss Aversion)
  → 문제 미해결 시 손실 강조
Solution (Gestalt 근접)
  → 기능을 3-4 그룹으로 청킹
Social Proof (사회적 증거)
  → 구체적 숫자 + 실명 후기
CTA (Hick's Law)
  → 선택지 최소화, 단일 행동 유도
```

### 대시보드
- Miller's Rule: 위젯 5-7개
- Gestalt 공통 영역: 카드로 정보 그룹핑
- Fitts' Law: 자주 쓰는 액션 상단/좌측

### 폼
- Hick's Law: 단계별 분할 (multi-step)
- Miller's Rule: 한 단계 3-5 필드
- 점진적 공개: 조건부 필드는 숨김

### Commerce (PDP)
- Von Restorff: 주 CTA(Add to Cart) 유일한 accent 컬러
- 사회적 증거: 리뷰/평점 CTA 근처 (구매자 98%가 리뷰 확인)
- Loss Aversion: 재고 부족/무료 배송 임박 표시
- Fitts: sticky add-to-cart (모바일 엄지 범위)

### SNS 콘텐츠
- Von Restorff: 주제 1개에 집중, 2-3 시각 요소 최대
- Miller: 3-5 단어 텍스트
- Gestalt 근접: 로고+브랜드 근접 배치

### 프레젠테이션
- Miller: 한 슬라이드 = 한 아이디어
- Von Restorff: 헤드라인 대형 bold (시각 차별화)
- Gestalt 연속: 슬라이드 간 논리 흐름 유지

### 영상
- Fitts: 자막/Lower Third 세이프존 배치
- Miller: 3-5초 인트로, 짧은 정보 단위
- 사회적 증거: 구독자 수/추천사 활용

### 브랜딩
- Von Restorff: 로고 = 기억에 남는 유일한 마크
- Gestalt 폐합: 불완전한 형태로 관여도 유도
