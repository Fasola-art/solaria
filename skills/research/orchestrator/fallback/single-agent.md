# Single Agent Fallback v6.0

다중 에이전트 단계가 흔들릴 경우에도 discovery-first 원칙은 유지한다.

## 최소 유지 단계

1. Question Reframing
2. Compact Discovery Planning
3. Open-World Discovery
4. Compact Candidate Normalization
5. Synthesis

## 절대 포기하지 않는 것

- raw candidate 기록
- local/emergent 표현 보존
- unresolved candidate 표시
- high-risk disclaimer

## 간소화되는 것

- deep reading 예산 축소
- targeted gap search 생략 가능
- coverage ledger를 간단 버전으로 축약
