## 형식 개요

| 형식 | 용도 | 방법론 출처 | 분량 |
|------|------|-------------|------|
| **Report** | 일반 상세 보고서 | - | 5-10페이지 |
| **Summary** | 빠른 요약 | - | 1-2페이지 |
| **Comparison** | A vs B 비교 | - | 2-5페이지 |
| **Quadrant** | 벤더/제품 포지셔닝 | Gartner Magic Quadrant | 3-5페이지 |
| **Hypothesis** | 가설 검증 결과 | McKinsey MECE | 3-5페이지 |
| **Maturity** | 성숙도 평가 | BCG BFF | 2-4페이지 |
| **PRISMA** | 문헌 리뷰 | PRISMA Statement | 5-10페이지 |
| **Hype Cycle** | 기술 성숙도 | Gartner Hype Cycle | 3-5페이지 |

### Magic Quadrant 시각화

```
              ▲ 실행 능력 (높음)
              │
    ┌─────────┼─────────┐
    │         │         │
    │ 도전자  │  리더   │
    │ (Challengers) │ (Leaders) │
    │         │    ★[A]│
    │    ◆[D] │  ●[B]  │
────┼─────────┼─────────┼────▶ 비전 완성도 (높음)
    │         │         │
    │ 틈새    │ 비전가  │
    │ (Niche) │(Visionaries)│
    │         │    ▲[C]│
    │    ■[E] │         │
    └─────────┼─────────┘
              │
              ▼ 실행 능력 (낮음)
```

**범례**: ★ 리더 | ● 리더 | ◆ 도전자 | ▲ 비전가 | ■ 틈새

| 형식 | 적합한 경우 | 분량 | 상세도 |
|------|-------------|------|--------|
| **Report** | 의사결정, 깊은 이해 필요 | 5-10페이지 | 높음 |
| **Summary** | 빠른 파악, 개요 | 1-2페이지 | 중간 |

| **Maturity** | 성숙도/수준 평가 | 2-4페이지 | 높음 |
| **PRISMA** | 학술 문헌 리뷰 | 5-10페이지 | 매우 높음 |
| **Hype Cycle** | 기술 트렌드 분석 | 3-5페이지 | 높음 |
