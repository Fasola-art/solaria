# Domain Presets Guide

도메인별 상세 프리셋은 기존 자산을 유지한다. 이 문서는 어떤 파일을 열어야 하는지 빠르게 안내한다.

## 먼저 볼 파일

- 범용/시장/비교/구매/학술 프리셋: `presets.md`
- 도메인별 우선 소스: `domain-sources/*.yaml`
- 전문 출력 형식: `formats.md`

## 사용 규칙

- 주제가 명확히 특정 도메인에 걸리면 `presets.md`를 먼저 본다
- 그래도 기본 흐름은 `질문 재정의 -> discovery planning -> open-world discovery -> dynamic taxonomy -> evidence search -> synthesis`를 유지한다
- 프리셋은 조사 방향을 좁혀 주는 보조 자산이지, 기본 사고 과정을 대체하지 않는다
