# 코덱 선택 가이드

> 출력 목적에 맞는 코덱/CRF/비트레이트를 선택한다.
> CRF(Constant Rate Factor): 낮을수록 고화질, 높을수록 고압축 (0=무손실, 51=최저화질)

---

## 용도별 권장 설정

| 용도 | 코덱 | CRF | 비트레이트 | 비고 |
|------|------|-----|-----------|------|
| YouTube 1080p | H.264 (libx264) | 18 | 8-12Mbps | `-preset slow` 권장 |
| YouTube 4K | VP9 (libvpx-vp9) | 10 | 35-45Mbps | 파일 크기 크지만 고화질 |
| 쇼츠 9:16 | H.264 (libx264) | 18 | 8-15Mbps | 세로 크롭 후 적용 |
| 프록시 | H.264 (libx264) | 28 | - | `-preset ultrafast` |
| 아카이브 | ProRes (prores_ks) | - | 최대 | 무손실에 가까운 원본 보존 |
| 웹 스트리밍 | H.264 (libx264) | 23 | 2-5Mbps | `-movflags +faststart` 필수 |
| GIF | - | - | - | 팔레트 2단계 방식 사용 |

## FPS 선택 기준

| 콘텐츠 유형 | 권장 FPS | 옵션 |
|------------|---------|------|
| 영화/시네마틱 | 24fps | `-r 24` |
| 일반 YouTube/쇼츠 | 30fps | `-r 30` |
| 게임 영상/스포츠 | 60fps | `-r 60` |

## 코덱별 특성

### H.264 (libx264)
- 범용성 최고 — 모든 플랫폼/기기 재생 가능
- YouTube, 쇼츠, 웹 배포에 적합
- `-preset`: `ultrafast` (빠름) → `slow` (고압축) → `veryslow` (최고압축)

### VP9 (libvpx-vp9)
- YouTube 4K 권장 코덱
- H.264 대비 약 40% 높은 압축 효율
- 인코딩 시간이 H.264보다 길다

### ProRes (prores_ks)
- Apple 생태계 (Final Cut Pro, DaVinci Resolve) 편집용
- 무손실에 가까운 고화질
- 파일 크기가 매우 크므로 아카이브 또는 중간 파일 용도

### H.265 (libx265)
- H.264 대비 약 50% 압축 효율 향상
- 호환성이 H.264보다 낮음 (구형 기기 재생 불가)
- 4K 아카이브, 스토리지 절약 목적에 적합

## CRF 빠른 참조

| CRF 값 | 화질 수준 | 파일 크기 | 권장 용도 |
|--------|---------|---------|---------|
| 0 | 무손실 | 매우 큼 | 테스트용 |
| 18 | 고화질 | 큼 | YouTube, 최종 출력 |
| 23 | 표준 | 중간 | 웹 스트리밍 |
| 28 | 보통 | 작음 | 프록시, 미리보기 |
| 35+ | 저화질 | 매우 작음 | 사용 비권장 |

---

## 픽셀 포맷

- `yuv420p`: YouTube 업로드 필수 (8bit, 범용)
- `yuv422p`: 방송/고품질 중간 파일
- `yuv444p`: 색상 최고 정확도 (ProRes 등)
- `yuv420p10le`: HDR 10bit (YouTube HDR 업로드)
