# 파이프라인 패턴 가이드

## 패턴 A: Sequential (순차)
A → B → C → D
- 용도: 단계별 의존성
- 예: 리서치 → 분석 → 보고서

## 패턴 B: Fan-Out & Merge (병렬 수집 → 합치기)
A → [B1 | B2 | B3] → C
- 용도: 독립 데이터 수집
- 예: Gmail + Calendar + GitHub 동시 수집
- 핵심: 같은 파일 동시 수정 금지

## 패턴 C: Conditional (조건 분기)
A → 조건 → B1 (참) / B2 (거짓)
- 용도: 상황별 다른 처리
- 예: 중요 메일만 알림

## 패턴 D: Hybrid (기본 패턴)
A → [B1 | B2] → C → [D1 | D2] → E
- 용도: 대부분의 실제 워크플로우
- 예: 리서치(순차) → 수집(병렬) → 분석(순차) → 변환(병렬) → 발행(순차)
